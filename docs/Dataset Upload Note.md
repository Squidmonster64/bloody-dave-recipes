# Bloody Dave Project Library Dataset — Current

This package contains the actual current curated Bloody Dave dataset available in this workspace:

- `recipes.json` — 41 recipes
- `Recipes/` — 41 individual Markdown recipe files
- `Recipe Index.md`

It does **not** contain the HelloFresh archive generated on the user's Mac. The following files must be added after the sweep finishes:

- `Archive/index.json`
- `Archive/recipes/`
- optionally `Archive/images/`

The archive files exist only on the Mac where the sweep is running until they are uploaded back into ChatGPT or the project library.
